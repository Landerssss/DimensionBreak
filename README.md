草稿
游戏主题：次元突破，玩家在一个游戏通关不同玩法视觉观感的关卡
草稿框架：玩家点击开始游戏后进入游戏，首先是
玩法一：二维平台跳跃，有一些技能，打过一些简单的NPC怪物后进入玩法二
玩法二：类似植物大战僵尸的平台，玩家可以种植一些简单的植物打僵尸打过后进入转场
玩法三：地面（植物大战僵尸的格子地图）（屏幕）开始颤抖，视角转成第一人称视角，此视角为固定视角，面朝一个方向，此方向上BOSS缓缓出现，只会在远处，主角永远无法移动到BOSS处，但是主角可以WASD移动躲避BOSS技能且不改变视角

正式程序设计部分：
游戏主界面
右下角按键为设置，展开有全屏非全屏按键、分辨率选项，声音调节按钮、垂直同步（不确定是否需要加）
全屏，垂直同步为勾选，声音调节为滑动进度条，分辨率为多个栏目选项，点开有很多个栏目，默认普遍的分辨率


游戏第一阶段
点击开始，屏幕会有景深效果，屏幕内容放大，展开后变成小人掉落到平台上，
界面：左上角有经验进度条和等级数字
角色拥有以下基础操作
1：WASD基础移动，空格跳跃，shift朝角色朝向瞬移一段距离（角色朝向根据操作者最后一次点击A还是D来决定）（有内置CD）
鼠标左键可以攻击，有攻击动作和基础数值
2：钩锁，角色点击“T”或者鼠标右键可以选择钩锁到鼠标存在的位置，若碰到障碍物则停止
钩锁的具体程序执行方案：
“碰到物体会取消动作掉落且有最大距离的虚空钩索”，
A:钩锁不需要依赖某个layer，依赖的是鼠标现在的位置，
B钩锁有极限距离，意思就是当我鼠标在半空中钩锁时，如果没有到最大距离，则直接到目标点
C如果中途碰到障碍物则直接下坠，到目标点时，直接下坠（现在的逻辑是勾到某个layer后需要空格或者重新T/鼠标右键才能取消，这没有必要，碰到任何东西直接下坠即可）
E玩家在钩锁途中点击WASD会立刻取消钩锁动作
F不需要为钩锁设计额外动作，简单即可
G如果鼠标位置超过钩锁极限距离，则执行从player位置到鼠标位置的最大距离点


角色数值需要在UNITY面板里面编辑，不能写死：移速，下坠速度，攻击力，暴击，等级等

新手村：玩家刚掉落到平台上背景会有浅色的按键提示，例如WASD移动

敌人NPC：敌人会默认在左右Xm巡逻，检测范围为半径Y米，玩家进入检测范围则一直以Z米/s的速度走向玩家，敌人不会跳跃
敌人NPC死亡：玩家获取经验值，不同类型的敌人（低级中级BOSS）获取的经验值不一样

玩家拥有以下技能：
技能的伤害=角色基础攻击力*暴击强度*技能倍率
以下所有技能的技能倍率都不写死，在Unity面板可以调节
下坠：等级要求无，当玩家身处空中时，双击S会立刻下坠（有内置CD），造成小范围伤害，下坠的过程路径会有颜色特效

突刺：有某等级要求，当达到此等级时，shift会变成突刺，过程路径会有颜色特效

游戏第二阶段
设定：2D小玩法
目的：获得游戏攻击道具
概述：动态玩家触发机关,随即转化为静态纸片并沿格子内路径移动
格子里面有三类
玩家（可移动）
炮台（不可移动）
敌人NPC（可移动）
程序代码执行逻辑：玩家移动 -> 敌人移动 -> 炮台开火 -> 结算死伤
规则如下
1：玩家与敌人NPC相撞则第二阶段游戏失败
2：失败后玩家从此触发器地点恢复掉落
3：玩家率先移动，玩家行动一次，NPC移动一次，若移动地点为边界外则移动不作数
4：玩家钩锁到触发器会变成静态纸片人，找到出口或者失败变为动态玩家
5：静态纸片人交替向左 45度、向 右 45度移动，意思就是我给出纸片的图片，然后玩家每次移动图片的展示就是45°，-45°交替循环，玩家思考的时间（不做移动指令的时候/待机的时候）纸片缓慢缩放造成细微的动态效果
6：炮台不可移动，炮台会发射圆形子弹打到离炮台最近的敌人NPC
7：敌人NPC受到炮台攻击三次则小时，变成泡沫消散
8：敌人NPC每次受到炮台攻击纸片会损伤，损伤表现为纸片图片边缘烧焦化，每次会使纸片烧焦变小
9：敌人NPC移动和主角一样，45°交替运行
10：敌人NPC不会移动到出口
11：移动到出口后会获得道具，根据通关的次数分别为
1,经验值，2，弓箭，3大量经验值，4，水魔爆（视频附件水魔爆）
12：难度会随着通关次数增加，根据算法算出可以通关但是难度依次递增的炮台数量，敌人位置，主角移动情况，出口位置
13：主角只会在第一列某行出现，出口只会在最后一列某行出现
14：炮台只会出现在左半边，敌人只会出现在右半边
15：敌人NPC碰到炮台，炮台散架爆炸
16：获得经验值左上角进度条会有增长动画
17：右上角为攻击模式（都为目前的左键触发，鼠标在界面点击切换
18：未解锁的武器为锁(🔒)图标

游戏第三阶段
地图存在悬崖（地图路径终点），在悬崖之前放一个触发器（玩家不可视），外显像一团黑雾，当玩家走到触发器后，视角丝滑切换到第一人称视角，此时检测条件
1：玩家至少有攻击方式弓箭，触发下一步
2：玩家只有普通攻击方式，第一视角界面出现一段话：前方的区域无法探索
下一步：
玩家任何按键均被锁定且玩家不可以执行任何操作
视角主动往悬崖下方看
下方是一片沙漠平地，有一点沙尘
玩家视角毅然决然跳了下去
当下降到沙漠平地后，看见的是空无一物只有沙尘漂浮，强烈的风还有一些滚动的风滚草
此视界面文字提示往前走
走了几米后
一个石头人怪物（BOSS）从地底爬起来，两只大手依次放在大地上，石头怪物下半身在地底，QA：怪物在远方
此时界面中上方文字提示：击败他！
文字提示几秒后转而变成怪物长长的红色血条
现在就开始了BOSS站
BOSS程序执行逻辑：
A.BOSS永远在最远方，玩家无法靠近
B.BOSS攻击方式可以参考附件：1召唤沙石（视频里面为冰锥）飞向主角，到达主角Z轴没打到则消失
2  有沙坑/岩石坑从靠近bossY轴处开始向着主角蔓延，例如BOSS附近两个坑，地图中间三个坑，几秒后主角附近也有几个坑
3 地面出现红色预警线，预警线连接此时主角与BOSS然后蔓延开来形成小长方形（参考草图），BOSS自己那扔（扔这个动作不做了）出一个极快的沙尘暴沿着虚线过来，范围为长方形宽度，
主角执行逻辑：
A.主角不可以转动视角，永远朝着BOSS
B.主角存在血量在屏幕正下方（第一阶段我也打算加血量，两个是一个东西，但是位置不一样，第一阶段我打算在左上角经验值旁边），当进入BOSS站，自己血量变成99999
但是同样的BOSS伤害也很高
C.主角只能使用弓箭和水魔爆，都需要做伪3D适配，在BOSS场景下，水魔爆变成了横着发射而不是和第一阶段一样竖着触发（参考视频动画）
